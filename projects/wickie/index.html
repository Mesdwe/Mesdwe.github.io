    Wickie: Defender of Kitties

    A 3D strategy game developed in Unity.

    View Source Code

    September 2021 - December 2021

    Wickie: Defender of Kitties is a 3D strategy game created by a team of five students from Abertay University. It was developed within 12 weeks using Unity.

    Contributions

    Lighthouse Abilities

    Implemented a component-based expandable ability system. As the core mechanic, the player controls a lighthouse to protect ships from monsters. The player can use resources collected during the game to upgrade lighthouse abilities.

    World Bending Shader

    Implemented an Animal Crossing style world bending shader, added in response to project feedback.

    Level Configs

    Used ScriptableObject as a container to store level configuration data for each level.
